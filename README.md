# GhostMode 👻

GhostMode is an AI-powered messaging assistant that helps users analyze messages, generate replies, and reduce overthinking in conversations.

---

## 🚀 Features

- Tone analysis
- AI-generated replies
- Decision helper
- Clean Streamlit UI
